# BMI Calculator

A simple Python command-line program that calculates Body Mass Index (BMI) and shows the corresponding category.

## Features

- Takes weight in kilograms
- Takes height in meters
- Calculates BMI
- Displays BMI rounded to 2 decimal places
- Classifies BMI as Underweight, Normal, Overweight, or Obese
- Handles invalid and negative inputs

## Technologies Used

- Python

## How to Run

1. Open the terminal in the project folder.
2. Run:

```bash
python3 BMIcalculator.py
